## Feature-shift ablation (2026-10-02, user request)
How AU/EU react to a test-time node-feature shift: switch `test_feature_noise` (cgnn/data/perturb.py,
docs/protocol.md), jobs `scripts/campaigns/aistats_fshift.jobs`, W&B `graph-uncertainty-aistats-fshift`,
queue log `outputs/logs/aistats_fshift_queue.log`. CGNN (best config, seeds 0-4) + M=5 ensemble, sigma in
{0, .25, .5, 1, 2, 4, 8}; CPU (3 x 16 threads; all GPUs were busy with other users at 12:00). `fshift-cgnn-reddit2`
waits for an idle GPU (not pinned). Analysis: `python scripts/analysis/aistats_results.py fshift`.
Reviewed (ml-reviewer: no blocking issues; fixes applied). Smoke (Roman, seed 0): CGNN EU +2% on shifted nodes at
sigma=4, AUROC 0.53.
- 12:11 all CPU fshift jobs done (no errors); `outputs/tables/aistats/fshift_long.csv`, `fshift_disentanglement.pdf`.
  Only Coauthor responds clearly (ensemble EU x3.1 / AU x1.8 at sigma=8, AUROC 0.75/0.68; CGNN EU/AU flat ~0.51-0.54)
  and Squirrel weakly (CGNN EU x1.11, AUROC 0.66; ensemble EU 0.63). Amazon/Roman/ArXiv: flat for every score.
- **Cause (probe, scratchpad `probe_shift.py`): the top-ranked v02/legacy backbones ignore node features.** Amazon,
  Roman, ArXiv, Squirrel backbones predict 1-2 classes, accuracy = majority share (Amazon 0.636, Roman ~0.12 vs 0.21,
  ArXiv 0.42, Squirrel 0.35); sigma=8 noise changes <=2% of predictions. Coauthor backbones: 11/11 classes, acc 0.91-0.94,
  sigma=8 changes 18-27% of predictions (acc -> 0.72-0.78). Amazon CGNN is also a constant classifier (acc 0.636 at
  every seed). Selecting by val OOD AUROC alone picks degenerate classifiers; their OOD scores must come from graph
  structure, not features. Affects the main table's baselines too: user decision pending.
- **Root cause of the degenerate models: early stopping/checkpointing on validation OOD AUROC** (vanilla
  `monitor: val_auroc`, CGNN `monitor: val_auroc_EU`). All 50 v02 Roman backbones are majority-class predictors
  (best val acc 0.210 = majority); ArXiv none above 0.511 (2 classes predicted). Selection among existing
  backbones cannot fix it (`scripts/campaigns/link_backbones_by_accuracy.py`, output kept in
  `checkpoints/aistats/fshift_acc/`, not used). Every CGNN sweep run on Amazon is a majority predictor (0.636).
